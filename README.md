# What is the Pause-YouTube-Shorts?
By removing scroll and next buttons, <br />
it prevents you from falling into the endless scrolling trap of Shorts,
helping you control your time spent on YouTube.

# How to Use it?
1. Download this repository and extract it.
3. Navigate to `chrome://extensions/`
4. Click the button`(Load the compressed extension)`
5. Select this project folder.
6. Finally, verify that it's working properly.
